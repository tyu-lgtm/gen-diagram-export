# GEN 図面 一括出力 v1.1

MIDAS GEN NX の MGTX / ANL を読み込み、応力ケース・登録平面・応力成分を選んでまとめて出力する非公式ブラウザーアプリです。部材番号図と断面番号図は MGTX のみで作成できます。読み込んだファイルはブラウザー内で処理し、サーバーには送信しません。

参照サイト [mgt2excel](https://rebuildon0.github.io/mgt2excel/) は単一部材の判定方法の参考にしています。元サイトのファイル・リポジトリーは変更していません。

## 起動

公開サイトのURLを開いてください。ローカルで動かす場合は、このフォルダーで次を実行します。

```powershell
python -m http.server 8000
```

その後 `http://localhost:8000/` を開きます（Windowsでは `py -m http.server 8000` でも起動できます）。

## いま試せること

- 「サンプルで試す」から架空モデルでケース・平面を複数選択
- M-y / M-z / Q-y / Q-z / N の応力成分を切り替え
- 選択したケース × 平面をブラウザー印刷または PDF 保存（印刷ダイアログの保存先を PDF にする）
- 現在の図をベクター SVG として保存
- MGTX の節点・部材・登録平面をローカルで読み取り
- ANL の梁・トラス断面力表を読み取り、検出した荷重ケースを選択
- 選択平面上の部材を抽出し、N / Q-y / Q-z / M-y / M-z の図をベクター SVG・印刷用 PDF に出力
- GEN NXの印刷図を参考にした縦型コンター凡例（6/12/18/24階調）とゼロ目盛を表示
- 応力コンターはANLの要素ごとの値で描画し、数値だけをMGTXの `*MEMBER` による単一部材ごとに表示（未指定要素は独立部材）。3点・All・5点・絶対最大・最小最大・非表示を切替可能
- 自動向きの数値は部材軸に沿わせつつ、上下逆にならない角度に補正
- MGTXに寸法ビューがある場合、ビューの向きから該当する寸法線・通り符号を選んで表示（`軸1` / `軸2` 以外の名前でも対応）。通り符号は部材より下方にある場合も表示
- モデル・寸法線・応力コンターの外形から、プレビュー・SVG・印刷が用紙内に収まるよう自動倍率調整。小型・大型モデルや座標原点から離れたモデルにも対応
- 文字フォント・サイズ・太さ・色・背景・向き、凡例サイズ、階調数、値の小数桁、塗り方、凡例位置を調整
- 図面タイトルを登録平面名・荷重ケース・応力成分から自動生成し、通り名や荷重期間、応力種別を任意指定
- 文字フォントに游明朝 / MS 明朝を選択
- 寸法線を既定で細く淡い灰緑色にし、線の太さ・色も調整
- 1本の外枠、右側の凡例欄、左下タイトルを今回の参照PDFと同じA4横の配置・比率に調整
- 部材番号図では MGTX の `*MEMBER`（単一部材指定）ごとに1つの番号を表示。指定済み部材は `iKEY`、未指定の線要素は要素番号で表示し、`*MEMBER` が無い場合は同種・同断面・同軸上の要素を自動連結
- 断面番号図も同じ単一部材単位で断面番号を1つずつ表示（同一指定部材内で断面が混在する場合は `2/3` のように併記）
- 部材番号図だけ、単一部材の両端から線に沿って少し内側に小さなオレンジの点を表示。断面番号図には表示しない。表示切替、直径（0.5～2 mm）、部材端から内側への距離（0.5～3 mm）を設定可能
- 文字サイズに 4 pt を追加

## 制限

サンプル図は操作確認用に生成した架空の図で、実解析値ではありません。実ファイル対応は提供された GEN NX 9.8 の MGTX / ANL 書式をもとに実装しています。荷重ケース・要素・平面の対応、部材ローカル軸の符号、結果の倍率は、実際の出力図と照合してから業務利用してください。表示オプションやページ構成は提供された応力図PDFとMIDASの公開設定項目を参考にしていますが、GEN NXの描画エンジンや完全な公式出力ではありません。ANLの断面力値は出力精度で丸められているため、PDFに表示された元データとの最終桁や同値時の最大・最小部材番号が異なる場合があります。また5点（I・1/4・中央・3/4・J）で描画するため、GEN NXのExact表示とは一致しません。

外部ライブラリーや外部フォントは使いません。モデルファイル・解析ファイルはブラウザー内だけで読み込み、送信しません。

部材端の点は参考PDFのオレンジ表示をもとにした試作表現です。複数の単一部材が同じ節点を端点に持つ場合も、各部材の内側に1点ずつ表示します。極端に短い要素では点が要素の35%より奥に入らないようにしています。
